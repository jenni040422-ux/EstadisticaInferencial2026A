# Acerca del conjunto de datos

Este conjunto de datos ofrece una visión detallada de las rutinas de ejercicio, los atributos físicos y las métricas de aptitud física de los socios del gimnasio. Contiene **973 muestras de datos**, incluyendo indicadores clave de rendimiento como la frecuencia cardíaca, las calorías quemadas y la duración del entrenamiento.

Cada registro también incluye datos demográficos y niveles de experiencia, lo que permite realizar un análisis de los patrones de actividad física, la progresión de los atletas y las tendencias relacionadas con la salud.

## Características principales

| Variable | Descripción |
|---|---|
| `Age` | Edad del socio del gimnasio. |
| `Gender` | Género del socio del gimnasio (masculino o femenino). |
| `Weight (kg)` | Peso del miembro en kilogramos. |
| `Height (m)` | Altura del miembro en metros. |
| `Max_BPM` | Frecuencia cardíaca máxima durante las sesiones de entrenamiento, medida en latidos por minuto. |
| `Avg_BPM` | Frecuencia cardíaca promedio durante las sesiones de entrenamiento. |
| `Resting_BPM` | Frecuencia cardíaca en reposo antes del entrenamiento. |
| `Session_Duration (hours)` | Duración de cada sesión de entrenamiento en horas. |
| `Calories_Burned` | Total de calorías quemadas durante cada sesión. |
| `Workout_Type` | Tipo de entrenamiento realizado, como cardio, fuerza, yoga o HIIT. |
| `Fat_Percentage` | Porcentaje de grasa corporal del miembro. |
| `Water_Intake (liters)` | Ingesta diaria de agua en litros. |
| `Workout_Frequency (days/week)` | Número de días de entrenamiento por semana. |
| `Experience_Level` | Nivel de experiencia del miembro: principiante (1), intermedio (2) o experto (3). |
| `BMI` | Índice de Masa Corporal, calculado a partir del peso y la altura. |

## Aplicaciones del conjunto de datos

Este conjunto de datos es útil para científicos de datos, investigadores de la salud y profesionales del fitness interesados en estudiar los hábitos de ejercicio y analizar la relación entre las características demográficas y fisiológicas de los participantes.

Entre sus principales aplicaciones se encuentran:

- Analizar los hábitos y la frecuencia de entrenamiento.
- Estudiar la relación entre la duración del ejercicio y las calorías quemadas.
- Examinar la relación entre la frecuencia cardíaca y la intensidad del entrenamiento.
- Comparar los resultados según el tipo de entrenamiento.
- Investigar la relación entre el peso, la altura, el IMC y el porcentaje de grasa corporal.
- Identificar diferencias en los hábitos de ejercicio según la edad, el género y el nivel de experiencia.

## Conclusión

La variedad de variables disponibles permite realizar análisis estadísticos descriptivos, calcular correlaciones y desarrollar modelos predictivos. De esta manera, el conjunto de datos facilita la identificación de patrones relacionados con el rendimiento físico y los hábitos de entrenamiento de los socios del gimnasio.
